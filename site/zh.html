    安装

    克隆仓库，在 Python 虚拟环境中安装命令行工具。

    启动服务

    在本地运行单节点代码存储服务。

  3. 03

    创建第一份变更

    创建工作区，提交变更，再落地到 main 分支。

终端 1 · 安装并启动服务 
git clone https://github.com/rizaust/open-scion.git
cd open-scion
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -e .
scion serve --data ./scion-data
终端 2 · 位于 open-scion/ 目录 
. .venv/bin/activate
scion init ../workspace --server http://127.0.0.1:7433
cd ../workspace
echo "hello, scion" > hello.txt
scion commit -m "First change" --author "you"
scion land --ref main
